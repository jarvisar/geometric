# Geometric Web App

This project is a web-based application that allows users to dynamically create geometric shapes by adjusting various parameters through sliders. The application utilizes HTML, CSS, and JavaScript to provide an interactive experience.

## Project Structure

```
geometric-web-app
├── src
│   ├── index.html       # Main HTML document
│   ├── app.js           # JavaScript logic for dynamic shape generation
│   └── styles.css       # CSS styles for the application
├── package.json         # npm configuration file
└── README.md            # Project documentation
```

## Features

- **Dynamic Shape Generation**: Users can adjust sliders to modify parameters such as the number of petals, line density, flower radius, and more.
- **Real-time Updates**: The geometric shape updates in real-time as users adjust the sliders, providing immediate visual feedback.
- **Responsive Design**: The application is designed to be user-friendly and responsive across different devices.

## Getting Started

To run the application locally, follow these steps:

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd geometric-web-app
   ```

3. Install dependencies (if any):
   ```
   npm install
   ```

4. Open the `src/index.html` file in your web browser to view the application.

## Usage

- Use the sliders to adjust the parameters of the geometric shape.
- The shape will update dynamically based on the selected values.
